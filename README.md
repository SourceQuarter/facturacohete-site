# facturacohete.com

Marketing site for FacturaCohete (Spanish, waitlist for now). Static HTML on GitHub Pages — public repo, free.

- The product app lives in the private `SourceQuarter/drupux` monorepo (`apps/facturacohete`) at `app.facturacohete.com`.
- Custom domain in `CNAME`; DNS in AWS Route 53. Unknown paths redirect home (`404.html`).
- Waitlist form: set `WAITLIST_URL` in `index.html` to the form link (Tally) before launch.
- Brand (violet rocket) is a **placeholder** until FacturaCohete's brand is decided.
